# 2026-10-10

## 修复"主题弹窗无法打开"

根因（设置页两个主题相关弹窗）：
- `ThemeColorSelectionDialogFragment` 的行布局用 `LayoutInflater.from(localized)` 解析 —— `localized = requireContext().withSelectedLanguage()` 是 `createConfigurationContext` 出来的**无主题** Context，`item_theme_color.xml` 里的 `?selectableItemBackground` / `?attr/textAppearanceBody1` 无法解析，`TypedArray.getResourceId/getDrawable` 抛 `UnsupportedOperationException: Failed to resolve attribute at index N`，弹窗还没显示就崩掉。这是全工程唯一一处用无主题 context 解析布局的地方（其他 Adapter 都用 `parent.context`）。
- 同类前科：commit ffc7170「修复语言选项无法打开的问题」也是无主题 context 导致 `MaterialAlertDialogBuilder` 失败。

改动：
- `ThemeColorSelectionDialogFragment.kt`：行布局改用 `LayoutInflater.from(parent.context)`（dialog 创建的主题化 ListView context），文案仍取 `localized`。
- `ThemeSelectionDialogFragment.kt`：对齐语言弹窗写法 —— `MaterialAlertDialogBuilder(requireActivity())` + 所有文案走 `localized.getString(...)`，条目文案由 `getItems(context)` 接收 context。

约定/注意：
- 工程里凡是 `withSelectedLanguage()` / `withLanguage()` 产出的 Context 都是**无主题**的，只能用来取字符串，不能用来 inflate 布局或建 Material 弹窗。
- 本机没有 Android SDK / local.properties，无法本地编译验证；构建走 GitHub Actions（JDK17 装 SDK，JDK8 跑 Gradle 5.4.1 / AGP 3.5）。
- 遗留观察：设置页「主题」分组标题与下方主题行的文案相同（都是 `R.string.theme`），分组标题不可点，容易误点，未改动。
